# Лабораторна робота № 2
## Перша сторінка

**Тема:** Вступ до веб-розробки.

**Мета роботи:** Підготувати середовище для веб-розробки у VS Code, створити першу HTML-сторінку, навчитися запускати її через Live Server та дослідити завантаження сторінки за допомогою DevTools.

### Хід роботи

Під час виконання лабораторної роботи було створено папку проєкту `taskboard` та файл `index.html` у середовищі VS Code. Для запуску сторінки було встановлено розширення Live Server.

У файлі `index.html` було створено HTML-документ із правильною структурою. На сторінку додано заголовок TaskBoard, абзаци з текстом, інформацію про автора, посилання на довідник MDN та зображення з атрибутом `alt`.

Сторінку було запущено через Live Server у браузері. Після зміни тексту та збереження файлу сторінка оновлювалася автоматично.

### Дослідження у DevTools

У вкладці Network було переглянуто запити, які браузер виконує під час завантаження сторінки. Для запиту `index.html` було перевірено адресу, метод запиту, статус відповіді та тип вмісту.

Також було перевірено роботу зображення. Після навмисної зміни шляху до `images/logo1.png` браузер не зміг знайти файл, а у вкладці Network з'явилася помилка 404. Після цього шлях було виправлено.

У вкладці Elements було змінено текст заголовка безпосередньо в браузері. Після оновлення сторінки зміна не збереглася у вихідному файлі. У вкладці Console було виконано команду `document.title` для перевірки назви сторінки та команду `document.body.style.background = "lightyellow"` для зміни кольору фону.

Після оновлення сторінки тимчасова зміна кольору фону зникла, оскільки її не було збережено у файлі HTML.

### Відповіді на контрольні запитання

**1. Яка адреса сторінки в браузері? З яких частин вона складається?**

Адреса сторінки має вигляд `http://127.0.0.1:5500/taskboard/index.html`. Вона складається з протоколу `http`, адреси локального комп'ютера `127.0.0.1`, порту `5500`,`taskboard` — папка проєкту. та шляху до файлу `index.html`.

**2. Скільки запитів зробив браузер при завантаженні сторінки і чому саме стільки?**

Кількість запитів можна побачити у вкладці Network. Браузер надсилає запит для отримання HTML-файлу та окремі запити для завантаження ресурсів, наприклад зображення. Тому кількість запитів залежить від того, які файли використовуються на сторінці.

**3. Що відбулось, коли було вказано неправильний шлях до зображення?**

Зображення перестало відображатися, оскільки браузер не зміг знайти файл за вказаним шляхом. У вкладці Network з'явилася помилка 404, після чого шлях до зображення було виправлено.

**4. Чому зміни, зроблені через DevTools, зникли після F5?**

Зміни, виконані через Elements або Console, не зберігаються автоматично у файлі `index.html`. Після оновлення браузер знову завантажує сторінку з файлу, тому тимчасові зміни зникають.

**5. Хто в цій схемі клієнт, а хто сервер?**

Клієнтом є браузер, який надсилає запити на отримання сторінки. Сервером є Live Server, який працює на локальному комп'ютері та передає браузеру HTML-файл і необхідні ресурси.
